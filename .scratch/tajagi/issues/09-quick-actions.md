# 09 — 컴포저 퀵 액션: 퀵버튼 + 퀵단축키 + 앱 카테고리 컨텍스트

**What to build:** 컴포저에 원클릭 퀵 액션 버튼 바와 퀵단축키(Cmd/Ctrl+1..0)를 추가한다. 버튼은 설정 가능한 "슬롯" 순서로 렌더링되고, macOS 접근성(AX)으로 감지한 전경 앱 카테고리(브라우저/에디터/메일/기타)에 따라 우선순위만 바뀐다. 내용 읽기/화면 인식은 제외(MVP).

**Blocked by:** 04 (composer integration), 06 (settings UI)

**Status:** ready-for-agent

**확정 설계 (그릴 2026-08-20):**
- 슬롯 10개 (Cmd+1..0). 처음 4개 기본 고정: `polish`, `translate_english`, `prompt_english`, `custom`. 슬롯 5~10은 **빈 상태**로 시작해 사용자가 설정에서 채움.
- 퀵단축키는 컴포저 포커스 중에만 동작, IME 조합 중엔 억제(Enter/Esc/Cmd+, 와 동일 패턴). 전역 기록 핫키와 무관(전역은 안 건드림).
- "컨텍스트"의 MVP 실체 = macOS AX로 전경 앱 카테고리 감지 → 퀵버튼 **우선순위(강조/순서)만** 변경. 내용/표본 읽기 및 화면 인식은 이후 트랙.
- AX 감지 불가(권한/플랫폼) 시 고정 기본 순서로 폴백.

- [ ] 백엔드: 전경 앱 카테고리 감지 (macOS AX) — `get_foreground_app_category()` 커맨드, 브라우저/에디터/메일/기타 분류, 비-macOS/권한 없으면 `other` 폴백 + 진단 로그
- [ ] 백엔드: 슬롯 설정 `quick_action_slots` (settings) — 기본 4개 = 기본 모드, 5~10 = 빈. get/set 커맨드 + 스트리밍/비스트리밍 기능과 무관한 순수 설정
- [ ] 컴포저: 퀵버튼 바 (슬롯 순서 렌더링, 첫 4 기본 백분, 빈 슬롯 숨김)
- [ ] 컴포저: Cmd/Ctrl+1..N → 해당 퀵 슬롯 실행, IME 조합 중 억제
- [ ] 컴포저: 카테고리 기반 우선순위 재정렬/강조 (MVP = 하이라이트 우선, 순서 안정)
- [ ] 설정 UI: 슬롯 5~10 에 액션(모드) 배정
- [ ] 검증: cargo test / lint / build / 라이브 컴포저 확인 (버튼 클릭 + Cmd+1..4 + 카테고리 전환)
