**What to build:** 앱을 실행하면 모든 표면(윈도우 제목, 트레이, 설정 창, 패키지/앱 id, 업데이터 구성)에 **타자기 (Tajagi)** 브랜딩이 적용되고, 기존 기능(음성 포함)이 전부 그대로 동작한다. upstream cjpais/Handy는 소프트 포크로 유지한다. 타자기 전용 개발 문서(CONTEXT.md, SPEC.md)는 이미 존재하며 이 티켓에서 정합성만 확인한다.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent
