# 06 — 설정 UI: 입력 소스·핫키·provider·모드·i18n

**What to build:** 설정 화면에서 ① 입력 소스(음성) 기본 OFF + 활성화 토글, ② 컴포저 핫키/커밋 단축키 구성, ③ provider(base URL·API 키·모델)·커스텀 인스트럭션 모드 관리, ④ ko/en 언어 전환을 사용할 수 있다. 첫 실행(first-run)은 모델 다운로드·마이크 권한 없이 컴포저 중심으로 안내된다.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 음성 입력 기본 OFF — 첫 실행/신규 사용자에게 모델 다운로드·마이크 권한 요청이 없다
- [ ] 설정에서 음성 활성화 시 기존 오디오 파이프라인·온보딩 진입점이 다시 노출되고 동작한다
- [ ] 컴포저 핫키·커밋 단축키 변경이 즉시 반영되고 충돌 시 경고
- [ ] provider 설정(기존 post_process UI 계승·표시명 transform) 재사용 확인
- [ ] Custom instruction 모드의 지시문 추가/편집/삭제
- [ ] 신규 키 ko/en 번역 완료 (기존 로케일은 우선 그대로 — 미번역 키는 en 폴백)
- [ ] 설정 변경이 저장되고 재시작 후 유지된다
